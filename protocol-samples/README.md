# Protocol samples (private)

Real scale capture logs must **not** be committed to this repository.

Place operational samples outside the repo, for example:

```text
C:\CanXeProtocolSamples
```

Expected DeviceTester text log naming:

```text
CanXe_COM1_yyyyMMdd_HHmmss.log
```

Optional sidecar files (Phase 2B DeviceTester):

```text
CanXe_COM1_yyyyMMdd_HHmmss.raw.bin
CanXe_COM1_yyyyMMdd_HHmmss.session.json
```

Use **CanXe Protocol Analyzer** (offline) to import and analyze these files.
